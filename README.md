# SmartKart

AI Powered Retail Billing with RFID & Intelligent Recommendations System

## Project Overview

SmartKart is an IoT and AI-powered smart retail cart designed to automate retail billing using RFID, provide weight-based security verification, enable digital payment, and generate personalized product recommendations.

## Technology Stack

- Python
- FastAPI
- MySQL
- Redis
- MQTT
- Flutter
- React
- Raspberry Pi
- RFID RC522
- HX711 Load Cell
- Arduino
- Machine Learning
